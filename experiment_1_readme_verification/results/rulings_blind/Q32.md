# Q32 — "pruned for publication with a signed manifest — see PRUNED.md … how to restore any of it from history" (blind ruling, model-made)

## Ruling
**contradicted** on "signed"; verified on manifest path and restorability. PRUNED.md exists at the cited path, its entries are git tree/blob ids that resolve, and restoration from history works — but nothing about it is signed under the inventory's definition (no detached signature, no signer-attested checksum of the manifest, no signer line; the committing commit is unsigned). The record's own description is "tree-sha manifest".

## Basis
- Manifest exists, 135 lines: `walkthrough/paper_pipeline/phase_1/resolve_runs/graph_v2/PRUNED.md:1-6` — "# PRUNED.md — evidence-prune manifest (2026-08-30) … NOTHING IS LOST: full git history is retained, and each entry pins the exact content by git object id (tree/blob sha at the pre-prune commit). To restore any entry: `git checkout <pre-prune-commit> -- <path>`."
- No signature: `grep -n -iE "sign|gpg|pgp|ssh-|sha256|checksum|attest" PRUNED.md` → no hits (the only "sign" match is the filename "HARNESS_REDESIGN.md.presplice"). `find … -name '*.sig' -o -name '*.asc' -o -name '*.sha256'` → only `behavior_pilot/PREREG_panel_equivalence.sha256`, unrelated to PRUNED.md. `git log -15 --format='%h %G?'` → every commit "N" (unsigned), including `6d01415b` (the prune commit). `git tag -n` → no tags. The prune commit describes it as "graph_v2/PRUNED.md (tree-sha manifest; …)" — content-addressed ids only, which the inventory says do NOT satisfy "signed".
- Restorable: `git cat-file -t a3581523…` → tree (first five ids sampled all resolve as trees); `git cat-file -t 5414a5e5…` (repair_graveyard) → tree; `git ls-tree -d 6d01415b^ …/runs/ds1` → "040000 tree 112cd21c… runs/ds1", matching the manifest's id for that entry; `git log --diff-filter=D -- …/runs/ds1` → `6d01415b`, so the "pre-prune commit" is `6d01415b^` (PRUNED.md leaves it as a placeholder rather than naming it).

## Arms
Both arms' states (contradicted) are right; both rest on the same facts (no signature markers, unsigned commits, resolvable object ids). Both arms' evidence decided it. Substance (on "signed"); no disagreement between arms.
