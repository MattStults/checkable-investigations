# Checkable investigations

Tools and experiments toward checkable, correctable investigations of AI agent
behavior: translate raw records into atomic claims with full provenance, under
mechanical checks, so conclusions can be audited and corrected without
re-running the analysis.

The proposal: [Proposing a symbolic evidentiary layer for alignment-event
investigations](https://mattstults.github.io/2026/08/30/checkable-investigations.html).
Background (the prior prototype whose machinery and discipline this builds on):
[retrospective](https://mattstults.github.io/2026/08/30/spec-retrospective.html)
and its [complete record](https://github.com/MattStults/semi-formal-document-analysis).
